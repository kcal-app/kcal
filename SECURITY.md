# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |

## Reporting a Vulnerability

kcal's maintainers recommend GitHub for reporting vulnerabilities.
Maintainers will do their best to verify, respond to and fix issues reported
on the platform.

[Disclose a Vulnerability on GitHub](https://github.com/kcal-app/kcal/security)
